Semantic HTML5 Portfolio

This project is a multi-page personal portfolio created for the HTML5 Semantic Structure & Accessibility assignment.


Pages


index.html — Home

about.html — About

projects.html — Projects

contact.html — Accessible contact form


Accessibility features


Semantic HTML5 landmarks: header, nav, main, section, article, and footer

Skip-to-content link

Keyboard-visible focus states

Accessible navigation with aria-current

Descriptive page titles and SEO-friendly meta descriptions

Proper form labels and required fields

aria-label and aria-describedby where useful

Responsive design

Reduced-motion support

Good color contrast


How to use

Open index.html in a browser. Replace Your Name and the sample project/about content with your own information.
